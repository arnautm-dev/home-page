This home navigator page it's a cutehome page adapted for Chrome principally. It's very adaptable and personalizable.

## Languages
For that project, I have used **HTML5**, **CSS3** and **JavaScript** (for google search and bubbles).

## Structure
```
project
├── shortcuts
│    └── shortcut icons
├── circles.js
├── google-search.js
├── icon.png
├── index.html
└── styles.css
```

## Design
The colours are:

- Background colour: ```rgb(196, 255, 195)```
- Bubbles: ```rgba(100, 200, 150, 0.5),
                rgba(120, 180, 200, 0.5),
                rgba(180, 150, 200, 0.5),
                rgba(150, 200, 100, 0.5),
                rgba(200, 100, 150, 0.5),
                rgba(100, 150, 200, 0.5),
                rgba(200, 180, 100, 0.5),
                rgba(100, 200, 200, 0.5),
                rgba(200, 150, 180, 0.5),
                rgba(150, 180, 200, 0.5)```

In the other hand, the font it's [Mulish](https://fonts.google.com/specimen/Mulish), connected from Google Fonts.
